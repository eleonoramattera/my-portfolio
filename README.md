# Portfolio di Eleonora Mattera

Sito single page in React + Vite con animazioni GSAP.

```bash
git clone https://github.com/eleonoramattera/portfolio.git
cd portfolio
npm install
npm run dev
```

L'app sarà disponibile su `http://localhost:5173`.

## Build di produzione
```bash
npm run build
npm run preview
```

## Stack
- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- CSS
